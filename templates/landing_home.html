About

SlideArchitect는 발표 초안 생성기보다 한 단계 더 깊다. AI가 개요와 슬라이드 본문을 만들고, 사용자는 웹 편집기에서 구조를 다듬고, 최종적으로 PPTX로 다시 렌더한다.

  • 주제 입력 → 템플릿 선택 → 생성 → 편집 → 다운로드 흐름.
  • 사용자 업로드 템플릿 라이브러리, 프로필 이미지, 결과 히스토리 포함.
  • Docker, Lightsail, Terraform 기반 운영 준비 완료.
