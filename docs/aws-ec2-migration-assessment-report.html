1. 문서 목적

본 문서는 현재 운영 중인 ai_ppt 서비스를 AWS EC2 환경으로 이전하기 전, 운영 서버에서 확인해야 할 실행 서비스, 포트, 런타임 버전, 데이터 보관 경로, 배포 방식, 백업 필요 범위를 정리하기 위한 사전 요청서입니다.

이 저장소 기준 서비스는 Django/Gunicorn 웹앱, Nginx reverse proxy, Node.js 기반 ppt-renderer, SQLite 파일 DB, 사용자 업로드/렌더 결과 파일, OpenAI API 및 SMTP 외부 연동으로 구성됩니다. 단, 실제 운영 서버의 프로세스와 데이터 용량은 아래 읽기 전용 명령 결과로 최종 확정해야 합니다.

운영 서버의 .env, API 키, SMTP 비밀번호, Django secret key, SSH 키, 인증서 private key는 원문 공유 대상이 아닙니다. 담당자는 키 이름, 파일 존재 여부, 마스킹된 설정 여부, 권한/소유자/수정일만 공유합니다.

2. 확인 범위 및 AWS EC2 이관 관점

구분현재 확인된 근거EC2 이관 관점
애플리케이션 Django 5.1.6, Python 3.12 계열, Gunicorn 23.0.0, OpenAI SDK 사용 EC2에 Python venv 또는 Docker 이미지로 배포. 운영 방식은 systemd 우선 검토
렌더러 Node.js 20, TypeScript, PptxGenJS, npm --prefix ppt-renderer 실행 EC2에 Node 20/npm 설치 또는 Docker 이미지 내부 포함 필요
웹 진입점 Nginx가 공개 80/443을 받고 Gunicorn 로컬 포트로 프록시 Security Group은 80/443만 공개, 앱 포트는 localhost 또는 내부만 허용
저장소 SQLite, media, rendered presentations, user templates가 로컬 파일 기반 EBS 볼륨에 데이터 경로 고정. 필요 시 S3 백업/정적 파일 분리 검토
외부 연동 OpenAI API, Gmail SMTP 또는 SMTP 서버 사용 EC2 outbound 443/587 허용, 비밀값은 SSM Parameter Store 또는 서버 환경 파일로 관리

12. 서버 담당자에게 전달할 요청 문안

안녕하세요. ai_ppt 서비스를 AWS EC2로 이전하기 위한 사전 점검을 진행 중입니다. 본 문서 9번의 명령은 서비스 재시작, 파일 수정, DB 접속, 데이터 변경 없이 현재 상태만 확인하는 읽기 전용 명령입니다. 실행 결과를 텍스트로 공유해 주세요. 단, .env, API key, password, private key, 인증서 key의 원문 값은 절대 포함하지 말고 키 이름과 마스킹된 상태만 공유 부탁드립니다.

13. 다음 진행 기준

서버 담당자 명령 결과가 확보되면 EC2 목표 사양, EBS 용량, 보안 그룹, 데이터 이전 범위, 배포 방식, 리허설 절차, DNS 전환 시간표, 롤백 기준을 확정합니다. 운영 서버 변경과 실제 데이터 이전은 별도 승인된 작업 계획서 기준으로 진행합니다.

명령 결과 해석 기준

  • ss와 ps는 현재 실행 중인 서비스와 포트를 증명하지만, 중지된 서비스까지 증명하지는 않습니다.
  • du/find 결과는 파일 기반 이관 범위를 산정하지만, 업무상 보관 필요성은 별도 정책 확인이 필요합니다.
  • systemctl cat과 Nginx 설정은 실행 경로와 라우팅을 증명하지만, 비밀값 원문은 공유하지 않습니다.
  • Docker 명령 결과가 비어 있으면 현재 운영은 systemd 직접 실행일 가능성이 높습니다.
